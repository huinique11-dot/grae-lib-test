소요시간 약 5분
💡 코드를 몰라도 100% OK / 클릭만 하면 완성!

컴퓨터를 꺼두어도 매일 아침 알림이 쏙!

아래 입력창 3개만 채운 뒤 [나만의 맞춤 코드 만들기] 버튼을 누르면 완성된 코드가 짠 하고 나타납니다.

1

카카오 개발자 '인증 키' 발급받기

최초 1회
  1. 아래 버튼을 클릭하여 카카오 디벨로퍼스에 접속 후 로그인합니다.
    카카오 디벨로퍼스 바로가기
  2. 상단 메뉴 [내 애플리케이션] ➔ [애플리케이션 추가하기] 클릭

    • 앱 이름: 도서관알림 / 사업자명: 본인이름 입력 후 저장

  3. 생성된 앱을 클릭하고 들어간 화면에 보이는 REST API 키를 복사합니다.
  4. 왼쪽 메뉴 [카카오 로그인] ➔ 활성화 상태를 `ON`으로 변경합니다.
  5. 같은 화면 아래쪽 [Redirect URI 등록] 버튼을 누르고 아래 주소를 입력 후 저장합니다.
  6. 왼쪽 메뉴 [카카오 로그인] ➔ [동의항목] ➔ 맨 아래 `카카오톡 메시지 전송` 항목을 [선택 동의]로 설정하고 저장합니다.
2

정보 입력하고 맞춤 코드 1초 만에 만들기

아래 3개 항목만 입력해 주세요

💡 [클릭] 버튼을 누르면 로그인 창이 엽니다. 동의 후 구글 페이지로 넘어갔을 때 맨 위 주소창의 https://www.google.com/?code=여기암호문자열 에서 code= 뒷부분만 복사해 오시면 됩니다.

👇 생성이 완료되면 [코드 전체 복사하기] 버튼을 누른 뒤, 구글 Apps Script 화면에 그대로 붙여넣으세요!

3

구글 Apps Script에 붙여넣고 클릭 2번하기

코드 수정 0개!
1

구글 Apps Script 접속 및 코드 붙여넣기

구글 시트 상단 메뉴 [확장 프로그램] ➔ [Apps Script] 접속 ➔ 기존 코드 다 지우고 방금 복사한 코드를 그대로 붙여넣은 뒤 `Cmd + S` (윈도우 `Ctrl + S`)를 눌러 저장합니다.

2

클릭 1: 카카오톡 최초 연결

상단 메뉴 드롭다운에서 step1_카톡연결하기 선택 후 [실행] 버튼 클릭!
(권한 허용 창이 뜨면: 고급 ➔ 안전하지 않은 페이지로 이동 ➔ 허용 클릭)

3

클릭 2: 발송 테스트하기

상단 메뉴 드롭다운에서 step2_카톡발송하기 선택 후 [실행] 버튼 클릭! 내 카카오톡으로 도서관 알림 메시지가 오면 연결 완성입니다! 🎉

카카오톡으로 알림 메시지가 무사히 수신되었다면 이제 4단계 타이머만 맞추시면 됩니다.
4

매일 원하는 시간에 자동 발송 타이머 설정

  1. Apps Script 좌측 메뉴의 시계 모양 아이콘 [트리거] 클릭
  2. 우측 하단 파란색 [+ 트리거 추가] 버튼 클릭
  3. 설정 옵션 지정:
    • 실행할 함수 선택: step2_카톡발송하기
    • 이벤트 소스 선택: 시간 기반
    • 트리거 기반 시간 유형: 일일 타이머
    • 시간대 선택: 오전 9시~10시 (원하는 발송 시간대)
  4. [저장]을 누르면 모든 세팅 완벽 완료! 🎉
